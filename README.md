# Growth Quest(成長クエスト)

将来なりたい姿に向けた毎日の習慣・収入・支出を可視化するPWA(Webアプリ)です。ビルド不要のプレーンなHTML/CSS/JavaScriptのみで作られており、データは端末内(localStorage)に保存されます。

## 機能

- **成長ダッシュボード(ホーム)**: 今日の達成率をリングで表示。「Daily Quests」(チェックすると即座に消える使い捨てのToDo)と、「Mood Board」(消えずに日付付きで蓄積される感情の記録。Google連携中は記録するたびに即座にGoogleスプレッドシートにも保存され、記録ごとに送信済み/未送信のバッジが表示される)
- **習慣トラッカー**: 習慣をスプレッドシート形式のグリッドでチェック。日ごとの進捗率・達成数・未達成数を集計行で表示。月単位で切り替え可能
- **収入**: 日単位で金額と「何の事業・内容で稼いだか」を記録。月ごとの一覧、年間の合計・棒グラフでの推移を表示し、月切り替えで年をまたいで閲覧可能
- **支出**: 日単位で金額とカテゴリ(食費・家賃など)を記録。収入タブと同じ構成で月次一覧・年間推移を表示
- **月次レポート**: 月が変わって初めてアプリを開いたとき、データがあれば自動的に先月分の収支・収入内訳・支出内訳・習慣の月間達成率をレポート表示。設定(⚙️)から「View This Month's Report」でいつでも手動表示も可能
- **目標**: なりたい将来像をタイトル・詳細メモ・期限・金額目標付きで管理し、習慣や収入と紐付け可能。期限までの残り日数、金額目標までの残り金額を「距離」として表示。さらにRPG風の「クエストマップ」で現在地をビジュアルに表示(金額目標があれば資金の進み具合、なければ紐づく習慣の継続度、どちらもなければ期限までの経過度合いを採用)
- **Google Sheets連携**(右上の⚙️設定から): 収入・支出の取引明細は月が変わったタイミングで、「今日の気持ち」は記録するたびに即座に、Googleスプレッドシートに追記。初回連携時に「成長クエスト家計簿」というスプレッドシート(「サマリー」「取引」「気持ち」の3タブ)を自動作成。シート内の表記(タブ名・見出し・「収入」「支出」の区分)は日本語で統一。「サマリー」タブには月別・年別・全期間の収入合計/支出合計/差額を自動集計。ヘッダーの色付け・見出し固定・収入行(緑)/支出行(赤)の色分けも自動適用され、設定画面の「Update Sheet」ボタンでいつでも再適用できる

## 月次レポート・Google Sheets同期の制限

これは「アプリを開いたタイミング」で前回との月の差分を見て処理する仕組みで、実際の月末(0時など)に自動でプッシュ通知や送信が行われるわけではありません。iOSのWebアプリはバックグラウンドで正確な時刻に処理を起動する仕組みを持たないため、この方式が現実的に達成できる範囲です。月をまたいで久しぶりにアプリを開いたときに、直前の月のレポート表示とGoogle Sheetsへの同期(連携中の場合)が行われます。

Google Sheets連携には、ご自身のGoogleアカウントでOAuthクライアントIDを発行する必要があります(設定画面に手順を記載)。自動同期は、ブラウザにGoogleのログインセッションが残っている場合のみポップアップなしで成功します。セッションが切れている場合は自動送信ができないため、設定画面から「Sync Now」を手動で押してください。ローカルの記録データ自体は、同期の成否に関わらず失われません。

「Mood Board」は記録するたびにその場で送信を試みるため、月次の取引明細より高頻度にGoogleへの接続が発生します。セッションが切れていると、記録するたびにログインのポップアップが必要になることがあります(頻繁だと感じる場合は、設定から一度きちんとログインし直すとセッションが更新されます)。送信できなかった記録は各記録に「Not synced」と表示され、ローカルには残ったままなので、設定画面の「Sync Now」でまとめて再送信できます。

なお、アプリ本体のUI(画面のラベル・ボタン・プレースホルダー)はすべて英語表記になっています。このREADME自体は開発メモとして日本語のままにしています。

## ビジュアルデザイン

ダーク基調・暖色オレンジ単色アクセントの「上質なプロダクト」系デザインシステムを採用しています(参考: Neue Montreal系タイポグラフィのブランドガイド、グロー背景を使ったダークUIのランディングページ、ウィジェット/統計カードのビジュアル)。

- **配色**: ほぼ黒に近い暖色ダーク背景(ライトモードは温かみのある紙色)+ アクセントカラーはオレンジ1色(`#FF6D29`)のみ。収入=グリーン、支出=レッドの意味的な色はそのまま維持しつつ、暖色パレットに馴染むトーンに調整
- **背景グロー**: ダークモードでは画面上部・右下にオレンジのラジアルグローを敷き、参考画像のような「光が差し込む」奥行きを表現
- **タイポグラフィ**: 見出しの英語表記部分にGoogle Fonts「Manrope」を採用。統計の数値は太く・字間を詰めて強調、セクション見出しやラベル類は小さく大文字+字間を広げた「ラベル感」のある表記に統一
- **カード・ボタン**: 角丸・枠線・影の強さをデザイントークン(CSS変数)として統一し、画面ごとにバラつきが出ないように統一。ボタンはピル形状+オレンジのグロー影、タップ時に軽く縮むアニメーションを追加
- **タブバー**: アクティブなタブのアイコンにオレンジのグロー付き円背景を追加。背景を半透明+ぼかし(backdrop-filter)にして浮遊感を演出
- グラフ(習慣の推移・収入/支出の日別推移)やクエストマップはCSS変数の色をそのまま参照する実装だったため、配色を変えるだけで自動的に新デザインに追従しています

追加で「近未来的なダークHUD」方向の指示を受け、以下も調整しました。

- **より漆黒に近い背景**(ダークモード基準色を`#080504`に)+ 中央下部からもオレンジのグローが滲むよう背景グラデーションを3層に拡張
- **グラスモーフィズム**: カード類の背景を半透明+`backdrop-filter: blur()`にし、背景のグローがカード越しに透けて見えるように変更
- **細身×極太のコントラスト**: 本文・ラベル類はGoogle Fontsの細めのウェイト(300〜600)、統計数値やパーセンテージは太字(800)+`tabular-nums`(桁がガタつかない等幅数字)で強調
- **グラフ・クエストマップの発光表現**: 折れ線グラフの線と先端の点、ハイライトされた棒グラフの棒に`shadowBlur`でオレンジのグローを追加。目標のクエストマップ(SVG)にも同様に光彩フィルターを適用

**機能・データ構造・ロジック・画面遷移は一切変更していません。** 変更したのは`styles.css`と、`app.js`内のグラフ描画関数に発光効果(shadowBlur)を追加した数行のみで、データの扱いや計算結果には影響しません。

さらに「黒とオレンジのコントラストを強く、発光をもっと強く」という指示を受け、以下を強化しました。

- 背景をほぼ純黒(`#030201`)に変更し、グロー(滲む光)の強さ・範囲を大幅に強化
- ボタン(Add/Save/＋)をアンバー→オレンジのグラデーション+強いグロー影に変更
- リングの達成率やカードの統計数値にオレンジの発光(text-shadow)を追加
- アクティブなタブアイコン・習慣グリッドの「今日」列など、アクセントカラーを使う箇所のコントラストを底上げ

## ファイル構成

```
index.html            画面構造(ホーム/習慣/収入/支出/目標の5タブ)
styles.css             スタイル(ライト/ダークモード対応)
app.js                  アプリロジック(状態管理・描画・月次レポート)
manifest.webmanifest    PWAマニフェスト(ホーム画面追加用)
service-worker.js       オフラインキャッシュ
icons/                  アプリアイコン(通常・maskable・Apple Touch Icon)
```

## ローカルで試す

```bash
cd /Users/okanaohiro/RPG
python3 -m http.server 8420
```

ブラウザで `http://localhost:8420/index.html` を開きます。

## iPhoneで試す

Macとスマホを同じWi-Fiに接続した状態でローカルサーバーを起動し、Mac側のIPアドレス(`ipconfig getifaddr en0` で確認)を使って `http://<MacのIP>:8420/index.html` にSafariでアクセスします。「ホーム画面に追加」すると、アイコン付きの単独アプリのように起動できます。

## データについて

すべてのデータ(習慣・収入・支出・目標・今日のやること・気持ちの記録)は端末のブラウザのlocalStorageに保存されます。ブラウザのデータ消去や「ホーム画面に追加」したアプリの削除でデータも失われるため、機種変更時などは注意してください。Google Sheets連携を設定すると、収入・支出の取引明細だけは月ごとにご自身のGoogleスプレッドシートにも追記され、端末のデータが消えても外部に記録が残ります(習慣・目標のデータはSheetsには送信されません)。
